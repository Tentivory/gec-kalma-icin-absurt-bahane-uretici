# GEÇ KALMA İÇİN ABSÜRT BAHANE ÜRETİCİSİ

## 🎯 Bu Proje Nedir?

Bu, insanlık tarihinin en büyük icadıdır. Einstein'in görelilik teorisinden daha önemli, Newton'un elmasından daha devrimci. 

**Geç kaldınız mı?** Artık sorun değil. Bu kod, sizin için bilimsel, felsefi ve tamamen absürt bahaneler üretir. Patronunuz bile 'tamam ya, mantıklı' diyecek.

### Özellikler (Abartılı)
- %99.7 başarı oranı (bilimsel araştırma yapıldı, makale yayınlanmadı)
- Kuantum dolanıklıklı bahane üretimi
- Varoluşsal krizleri bahane olarak kullanabilme yeteneği
- NASA onaylı (belge kayboldu ama inanın)
- TentiAŞ tarafından desteklenmektedir (destek = 'tamam kardeş')

## 🚀 Kullanım

```bash
python bahane_uretici.py
```

Veya daha ciddi olmak için:

```bash
python3 bahane_uretici.py
```

Çıktı örneği:
```
Bahane üretiliyor... Lütfen bekleyin (ciddi bilimsel işlemler devam ediyor)...
.
..
...

🎯 RESMİ BAHANE:
Otobüs şoförü varoluşsal bir kriz geçirdi ve durakta 45 dakika felsefe yaptı.

Bu bahane %99.7 oranında işe yarar. Kalan %0.3 için avukat tutun.
```
